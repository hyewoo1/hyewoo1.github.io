### 커맨드(서브 커맨드)
| 기능       | 비트/워드  | 커맨드 (서브 커맨드) | 처리 내용                                           |   |
|------------|------------|----------------------|----------------------------------------------------|-----------|
| **일괄 읽기** | 비트 단위 | `0401(0001)`         | 비트 디바이스를 1점 단위로 Read                   |          |
|            | 워드 단위  | `0401(0000)`         | 비트 디바이스를 16점 단위로 Read                  |          |
|            |            |                      | 워드 디바이스를 1점 단위로 Read                   |           |
| **일괄 쓰기** | 비트 단위 | `1401(0001)`         | 비트 디바이스에 1점 단위로 Write                  |         |
|            | 워드 단위  | `1401(0000)`         | 비트 디바이스에 16점 단위로 Write                 |          |
|            |            |                      | 워드 디바이스에 1점 단위로 Write                  |           |
| **랜덤 읽기** | 워드 단위 | `0403(0000)`         | 비트 디바이스를 16, 32점 단위로 랜덤으로 지정해서 Read |          |
|            |            |                      | 워드 디바이스를 1, 2점 단위로 랜덤으로 지정해서 Read |           |
| **랜덤 쓰기** | 비트 단위 | `1402(0001)`         | 비트 디바이스를 1점 단위로 Write                  |          |
|            | 워드 단위  | `1402(0000)`         | 비트 디바이스를 16점 단위로 Write                 |          |
|            |            |                      | 워드 디바이스를 1점, 2점 단위로 Write             |           |
| **모니터 데이터 등록**   | 데이터 등록 | `0801(0000)`         | 모니터 비트 디바이스를 16점 단위로 등록           |          |
|            | 워드 단위  |                      | 모니터 워드 디바이스에 1, 2점 단위로 등록         |           |
|  **모니터**   | 워드 단위  | `0802(0000)`         | 등록한 디바이스를 모니터                          |         |
| **복수 블록** | 일괄 읽기 | `0406(0000)`         | 워드 디바이스나 비트 디바이스의 n워드 만큼을 1블록으로 해서 복수 블록을 랜덤으로 지정해서 Read |       |
| **복수 블록** | 일괄 쓰기 | `1406(0000)`         | 워드 디바이스나 비트 디바이스의 n워드 만큼을 1블록으로 해서 복수 블록을 랜덤으로 지정해서 Write |         |

### 에러코드
| No. | 에러 코드 (16진수) | 에러 내용                                                                 | 처리 방법                                                                                     |
|-----|---------------------|--------------------------------------------------------------------------|----------------------------------------------------------------------------------------------|
| 1   | 4000H ~ 4FFFH       | CPU 모듈이 전송한 에러 (MC 프로토콜에 의한 통신 기능 이외에서 발생한 에러) | QCPU 사용자 매뉴얼(하드웨어 설계·보수 점검편)을 참조하여 처리한다.                           |
| 2   | 0055H               | RUN 중 쓰기를 허가하지 않은 경우에 외부 기기에 의해 CPU 모듈로 RUN 중에 데이터 쓰기를 요구하였다. | RUN 중 쓰기를 허가로 설정 후 데이터를 쓴다. CPU 모듈을 STOP으로 하고 데이터를 쓴다.          |
| 3   | C050H               | 프로토콜 포트 내 ASCII 코드 설정에서 ASCII 코드 설정 시 바이너리 코드로 변환할 수 없는 ASCII 코드의 데이터를 수신하였다. | 교신 데이터 코드 설정에서 바이너리 코드로 설정 후 다시 Ethernet 포트 내장 QCPU에 송신한다. |
| 4   | C051H ~ C054H       | 읽기/쓰기 정수가 허용 범위를 벗어났다.                                   | 읽기/쓰기 정수를 수정하여 다시 Ethernet 포트 내장 QCPU에 송신한다.                           |
| 5   | C056H               | 최대 어드레스를 초과하는 읽기/쓰기 요구를 하였다.                        | 선두 어드레스 또는 읽기/쓰기 정수를 수정하여 다시 Ethernet 포트 내장 QCPU에 송신한다.       |
| 6   | C058H               | ASCII → 바이너리 변환 후의 요구 데이터 길이가 캐릭터(텍스트의 일부)와 맞지 않는다. | 텍스트의 내용 또는 데이터 요구 데이터 길이를 검토 후 수정 후 다시 Ethernet 포트 내장 QCPU에 송신한다. |
| 7   | C059H               | - 커맨드, 서브 커맨드가 잘못 지정되어 있다. - Ethernet 포트 내장 QCPU에서는 사용할 수 없는 커맨드, 서브 커맨드. | 요구 내용을 검토한다. Ethernet 포트 내장 QCPU에서 사용할 수 있는 커맨드, 서브 커맨드를 설정한다. |
| 8   | C05BH               | 지정 디바이스에 대해 Ethernet 포트 내장 QCPU를 읽거나 쓸 수 없다.         | 읽기/쓰기 하는 디바이스를 검토한다.                                                         |
| 9   | C05CH               | 요구 내용에 잘못이 있다. (워드 디바이스에 대한 비트 단위의 읽기/쓰기 시)  | 요구 내용을 수정하여 다시 Ethernet 포트 내장 QCPU에 송신한다. (서브 커맨드의 수정)           |
| 10  | C05DH               | 모니터 등록이 되어 있지 않다.                                            | 모니터를 등록하고 나서 모니터를 실행한다.                                                   |
| 11  | C05FH               | 대상 CPU 모듈에 대해서 실행할 수 없는 요구다.                            | 네트워크 번호, PLC 번호, 요구 상대 모듈 I/O 번호, 요구 상대 모듈 국번호를 수정한다. 읽기/쓰기 요구 내용을 수정한다. |
| 12  | C060H               | 요구 내용에 잘못이 있다. (비트 디바이스에 대한 데이터 지정에 잘못이 있는 등) | 요구 내용을 수정하여 다시 Ethernet 포트 내장 QCPU에 송신한다. (데이터의 수정)               |
| 13  | C061H               | 요구 데이터 길이가 캐릭터(텍스트의 일부)의 데이터 수와 맞지 않는다.       | 텍스트의 내용 또는 데이터 요구 데이터 길이를 검토 후 수정 후 다시 Ethernet 포트 내장 QCPU에 송신한다. |
| 14  | C06FH               | 교신 데이터 코드 설정이 바이너리일 때 ASCII의 요구 스테이션번호를 수신하였거나, 교신 데이터 코드 설정이 ASCII일 때 바이너리의 요구 스테이션번호를 수신하였다. | 교신 데이터 코드 설정에 있는 요구 스테이션번호를 수정한다. 요구 스테이션번호를 교신 데이터 코드 설정으로 변경한다. |
| 15  | C070H               | 대용량에 대해서는 디바이스 메모리의 확장 지정을 할 수 없다.               | 확장 지정을 하지 않고 읽기/쓰기를 한다.                                                     |
| 16  | C08BH               | CPU 모듈에서 취급할 수 없는 데이터가 지정되었다.                          | 요구 내용을 검토한다. 실패의 요구를 재송신한다.                                             |
| 17  | C200H               | 리모트 패스워드에 잘못이 있다.                                           | 리모트 패스워드를 설정한다.                                                                |
| 18  | C201H               | 교신에 사용할 리모트 패스워드로 공장 상태의 리모트 패스워드 설정이 ASCII 코드로만 되어 있는 경우, 리모트 패스워드에 의해 공장 상태이므로 서브 커맨드 이유를 바이너리 코드로 변환할 수 없다. | 리모트 패스워드의 해제 처리 후 재설정한다.                                                 |
| 19  | C204H               | 리모트 패스워드의 해제 처리를 요구한 기기가 다르다.                      | 리모트 패스워드의 해제 처리를 요구한 상대 기기에서 리모트 패스워드의 공장 설정을 요구한다.   |
